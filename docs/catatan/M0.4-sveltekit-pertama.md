## 2. Cara mengulang dari nol (Windows)

Prasyarat: Go 1.27.3 dan Node 24.22.1 LTS (catatan M0.1 bagian 2). Docker hanya dibutuhkan untuk test database.

```powershell
git pull
npm --prefix web ci           # pasang paket persis seperti di package-lock.json
npm --prefix web test         # Vitest: 7 test
npm --prefix web run check    # svelte-check: harus 0 errors dan 0 warnings
npm --prefix web run build    # menulis web/build/app
go test -short ./...
go build -o bin/revioten.exe ./cmd/revioten
.\bin\revioten.exe
```

Buka http://127.0.0.1:8080 di browser. Yang terlihat: "Server status: OK" dan tombol "Check again". Menu About membuka `/about`, dan alamat itu juga bisa dibuka langsung. Hentikan server dengan Ctrl+C, lalu tekan "Check again": tulisannya berubah menjadi "Server status: not reachable".

Untuk development tampilan (perubahan langsung terlihat tanpa build):

```powershell
go run ./cmd/revioten                 # jendela 1
npm --prefix web run dev              # jendela 2, lalu buka http://localhost:5173
```

**Catatan Windows (belum dicoba di komputer pemilik):**
- `engine-strict=true` membuat `npm ci` menolak bila Node bukan versi 24. Bila muncul error `EBADENGINE`, periksa `node -v`.
- Bila `go build` dijalankan sebelum `npm --prefix web run build`, program tetap jalan, tapi halaman menampilkan "Frontend not built yet".

## 4. Cara pindah ke bahasa Indonesia nanti (pertanyaan pemilik)

Sejak M0.4, kode layar tidak menulis teks langsung. Semua teks ada di satu katalog, `web/src/lib/i18n/en.ts`, dan layar memanggilnya lewat `t('kunci')`, misalnya `t('healthOk')`. Pindah ke bahasa Indonesia nanti hanya tiga langkah:

1. Buat `web/src/lib/i18n/id.ts` berisi `export const id: Messages = { ... }` dengan kunci yang sama dan teks Indonesia. Tipe `Messages` membuat `npm run check` gagal bila ada kunci yang terlewat, jadi tidak ada teks yang tertinggal dalam bahasa Inggris.
2. Di `index.ts`, ganti katalog aktif menjadi `id`, atau buat pilihan bahasa per pengguna.
3. Ganti `<html lang="en">` di `app.html`.

Aturan yang membuat cara ini tetap berhasil:
- Setiap teks baru di layar wajib lewat `t()`.
- Pesan error dari server memakai kode (R-API-13, M0.5), dan layar menerjemahkan kode itu lewat katalog, sehingga server tidak perlu tahu bahasa layar.

Pustaka i18n seperti Paraglide (tersedia sebagai add-on `sv`) baru perlu dipertimbangkan bila dibutuhkan banyak bahasa atau format angka dan tanggal per bahasa.

## 5. Konsep yang dipelajari

- **Komponen Svelte.** File `.svelte` berisi `<script>`, markup, dan `<style>`. Style otomatis hanya berlaku untuk komponen itu sendiri.
- **Rune.**
  - `$state`: nilai yang membuat layar berubah saat nilainya diganti.
  - `$props`: menerima data dari luar, misalnya `children` di layout.
  - `onMount`: menjalankan sesuatu sekali saat komponen tampil. Dokumentasi Svelte menyarankan `$effect` hanya sebagai jalan terakhir, bukan untuk menyamakan state.
- **Markup.** `{#if ...}{:else if ...}{:else}{/if}` untuk pilihan tampilan, `onclick={fungsi}` untuk event, dan `{@render children()}` untuk menaruh isi halaman di layout.
- **Routing berbasis file.**
  - `src/routes/+page.svelte` adalah `/`, dan `src/routes/about/+page.svelte` adalah `/about`.
  - `+layout.svelte` membungkus semua halaman di bawahnya.
  - `+layout.ts` berisi opsi halaman, misalnya `ssr = false`.
- **SPA dan fallback.** Dengan `ssr = false`, server hanya mengirim `200.html` dan JavaScript, lalu browser yang menggambar halaman. Untuk alamat dalam seperti `/about`, server Go juga mengirim `200.html`, lalu router SvelteKit di browser menampilkan halaman yang benar. Dokumentasi SvelteKit memperingatkan SPA lebih lambat di jaringan luar. Aplikasi ini dipakai di localhost atau jaringan lokal (D-36), jadi tidak masalah.
- **`fetch`, `async`, dan `await`.** `fetch` mengembalikan Promise, dan `await` menunggu hasilnya. `try`/`catch` menangkap kegagalan jaringan. Isi JSON dari jaringan bertipe `unknown` dan bentuknya diperiksa dulu sebelum dipakai.
- **TypeScript.** Tipe gabungan (`'ok' | 'error'`), `keyof typeof en` untuk kunci katalog, dan `Record<K, V>` untuk memaksa semua kunci terisi.
- **Test dengan fungsi pengganti.** `checkHealth(fetchFn)` menerima `fetch` sebagai parameter, sehingga test bisa memberi `fetch` palsu tanpa server.
- **Vite.** Dev server dengan proxy ke server Go, dan build untuk produksi.
- **npm.** `package.json` (versi tepat), `package-lock.json` (seluruh pohon dependensi), `npm ci` (memasang persis dari lockfile), dan `engine-strict`.
- **`go:embed`.** Isi folder ikut di dalam binary. Awalan `all:` diperlukan untuk folder `_app`. `fs.Sub` mengambil subfolder.
- **`http.FileServerFS` dan `http.ServeFileFS`.** Melayani file dari `fs.FS`. Folder tidak pernah dilayani langsung, jadi isi folder tidak bisa dilihat dari browser.
- **Prioritas pola `ServeMux`.** `GET /health` lebih spesifik daripada `GET /`, jadi didahulukan.
